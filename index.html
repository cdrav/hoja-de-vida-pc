Manual de Usuario

1. Información del Usuario y Ubicación:

  • Nombre Responsable: Ingresa el nombre completo del usuario principal del equipo.
  • Cédula (CC): Número de identificación del responsable.
  • Cargo: Puesto de trabajo del responsable.
  • Usuario de Red / Correo: Nombre de usuario de dominio o dirección de correo electrónico institucional.
  • Ubicación: Departamento o área donde se encuentra el equipo.

2. Hardware y Especificaciones:

  • Tipo de Equipo: Selecciona el tipo de equipo (PC Escritorio, Portátil, etc.).
  • Marca, Modelo, Serial, Placa Inventario: Datos identificativos del equipo.
  • Procesador, Memoria RAM: Especificaciones técnicas principales.
  • Almacenamiento: Tipo y capacidad del disco principal.

3. Detalle de Periféricos:

  • Para cada periférico (Monitor, Teclado, Mouse, Impresora, Scanner, UPS/Regulador), ingresa su Marca, Modelo, Serial y Placa/Activo si aplica.

4. Software y Licenciamiento:

  • Sistema Operativo: Selecciona el SO instalado y si la licencia es OEM o por Volumen.
  • Microsoft Office: Selecciona la versión de Office y su estado de activación.
  • Software Adicional: Marca los programas adicionales instalados.

5. Red y Seguridad (Auditoría):

  • Nombre de Equipo, IP, MAC Address (LAN/WIFI), Gateway, DNS: Configuración de red del equipo.
  • Chequeo de Seguridad: Marca las opciones de seguridad aplicadas.

Firmas:

  • REALIZADO POR (SISTEMAS): Nombre del técnico que realiza la ficha.
  • RECIBIDO A SATISFACCIÓN (USUARIO): Nombre del usuario que recibe el equipo o valida la información.

Una vez completado, haz clic en "GUARDAR EN DRIVE" para enviar la información. Puedes usar "IMPRIMIR PDF" para generar una copia.
